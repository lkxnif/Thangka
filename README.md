## 唐卡传承与创新设计研究报告

这是一个使用 Docsify 搭建的在线文档站点，用来展示和阅读《唐卡传承与创新设计研究报告》及相关章节内容。

### 阅读导航

- 可以通过左侧侧边栏在各章节之间切换：
  - 总体报告
  - 唐卡概述与历史溯源
  - 唐卡传承现状调研
  - 总结及展望
  - 参考资料
  - 附录： 中国藏族文化艺术彩绘大观（618米）等

### 本地预览方式

- **方式一（推荐，Node.js 用户）**：在项目根目录执行：

  ```bash
  npx serve .
  ```

  然后在浏览器中访问命令行中提示的地址（例如 `http://localhost:3000`）。

- **方式二（Python 用户）**：在项目根目录执行：

  ```bash
  python -m http.server 8000
  ```

  然后在浏览器中访问 `http://localhost:8000`。

打开根目录下的 `index.html`，即可以 Docsify 形式浏览所有 Markdown 文档。
